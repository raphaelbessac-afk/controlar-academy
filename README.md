# Controlar Academy · Protótipo

Jogo de treinamento em segurança do paciente e prevenção de infecção para equipes de CTI.
Protótipo com a trilha **Higiene das Mãos** em três níveis: perguntas, peças para combinar e caso de ensino.

- Para jogar: abra o link do GitHub Pages no celular.
- Para revisar o conteúdo técnico: edite apenas `content.js`.
- Conteúdo pendente de validação técnica.
